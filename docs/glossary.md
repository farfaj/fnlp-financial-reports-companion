# Glossary

| Term | Meaning in this companion |
|---|---|
| FNLP | Financial natural language processing: NLP applied to reports, filings, news, disclosures, and other financial text. |
| FNP | Financial narrative processing: the paper's organizing concept for turning unstructured financial narratives into structured information. |
| ESG | Environmental, social, and governance factors and disclosures. |
| XAI | Explainable artificial intelligence: methods that make model outputs more interpretable and traceable. |
| LLM | Large language model based on transformer architectures and large-scale training. |
| RAG | Retrieval-augmented generation: generation conditioned on retrieved source material. |
| OCR | Optical character recognition for converting document images into machine-readable text. |
| NER | Named entity recognition for organizations, people, dates, amounts, metrics, and other entities. |
| QA | Question answering over financial text or documents. |
| MD&A | Management discussion and analysis, a narrative section of corporate reporting. |
| XBRL | eXtensible Business Reporting Language, a structured standard for digital business reporting. |
| GRI | Global Reporting Initiative sustainability reporting standards. |
| SASB | Sustainability Accounting Standards Board industry-oriented disclosure standards. |
| SHAP | Shapley Additive exPlanations, a feature-attribution approach. |
| LIME | Local Interpretable Model-agnostic Explanations. |
| GNN | Graph neural network for graph-structured entities and relations. |
| Document AI | Methods that jointly reason over document text, layout, images, and structure. |
| Calibration | Agreement between a model's confidence and its empirical correctness. |
| Domain shift | A change in data distribution across markets, periods, companies, sectors, languages, or document formats. |
