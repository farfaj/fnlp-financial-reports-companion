# Roadmap

## Current phase — research companion

Version 1.x is intentionally documentation-first. Its purpose is to make the review's scope, taxonomy, evidence aggregates, practical landscape, and research agenda easier to navigate and cite.

Planned maintenance includes factual corrections, link maintenance, accessibility improvements, and clearer provenance notes.

## Later phase — working implementation

A future, separately scoped phase may develop a Python pipeline for financial-report extraction. That work is **not part of this release** and should begin with explicit choices about:

- native PDF parsing versus OCR and document-image processing;
- table, reading-order, and section extraction;
- Arabic–English alignment and morphology-aware preprocessing;
- ESG metric schemas and domain ontologies;
- retrieval, citation grounding, and hallucination controls;
- evaluation datasets, licensing, privacy, and regulatory constraints;
- human review, explainability, audit trails, and deployment cost.

No implementation date, model, benchmark, or performance target is promised by this roadmap.
